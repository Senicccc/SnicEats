# SnicEats 🍔

**SnicEats** is a simple food ordering website that simulates a fast-food brand experience with a clean user interface. It includes sections such as Landing, Menu, Checkout, Contact, and About pages.

## 🔗 Live Demo

- GitHub Pages: [https://senicccc.github.io/SnicEats/](https://senicccc.github.io/SnicEats/)
- Vercel: [https://snic-eats.vercel.app/](https://snic-eats.vercel.app/)

> ⚠️ **Note:** Cart and payment functions are not accessible on the live demo versions due to limitations in deployment.

## 🚀 Features

- Interactive UI sections (Landing, Menu, Contact, About, Checkout)
- Highlighted top-selling food items
- Static location & contact form
- Product display with basic pricing
- Fully responsive layout

- HTML5
- CSS3
